# Sitemap Page

This folder contains the Sitemap page for ZeroCalculator.net.

## Files

- `index.html` - The main Sitemap page with all site links
- `sitemap.css` - Dedicated CSS styles for the Sitemap page
- `README.md` - This documentation file

## Features

- Lists all main pages and calculators
- Includes descriptions for each calculator
- Quick links sidebar with important links
- Fully responsive design
- Theme-aware styling
- Uses the same header and footer components as other pages

## Structure

The sitemap is organized into sections:
- Main Pages (Home, About Us)
- Calculators (all available calculators with descriptions)
- Quick Links (GitHub, About, Home)
