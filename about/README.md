# About Us Page

This folder contains the About Us page for ZeroCalculator.net.

## Files

- `index.html` - The main About Us page with the story content
- `about.css` - Dedicated CSS styles for the About Us page
- `README.md` - This documentation file

## Features

- Displays the story behind ZeroCalculator.net
- Includes a sidebar with links to all calculators
- Fully responsive design
- Theme-aware styling
- Uses the same header and footer components as other pages

## Content

The page content is populated dynamically from `../helpers/text-config.js` using the `aboutUs` configuration.
